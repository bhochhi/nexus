# Changelog

Notable changes to this project are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-02

### Added

- Governed LangGraph conversation runtime with durable state and deterministic
  execution controls.
- Versioned, hot-reloadable skill catalog and portable `SKILL.md` authoring.
- Approved knowledge, guided balance, internal transfer, online-ID recovery,
  and live-agent handoff capabilities.
- FastAPI streaming service, terminal client, and development Streamlit member
  and representative interfaces.
- OpenAI, Amazon Bedrock, and deterministic model-provider adapters.
- Privacy-safe audit and observability integrations.
- Portable platform specifications, ADRs, contracts, capability specifications,
  and cross-agent spec-driven development workflow.

### Release scope

- This is a source release of a development proof of concept.
- The repository uses synthetic data and mock business integrations.
- It is not certified for production financial-services use.
- npm and PyPI packages are not published as part of this release.
